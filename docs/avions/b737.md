# Boeing 737-800 (Laminar)

```sh
bin/pepit-cockpit config/avions/b738-laminar
```

Le profil `config/avions/b738-laminar/` relie le matériel OpenCockpits et EFDE au Boeing 737-800 livré avec X-Plane 12. C'est le premier profil relié à X-Plane : il sert de modèle pour un avion aux commandes standard.

| Fichier | Matériel | Ce qu'il relie |
|---|---|---|
| `mcp.yaml` | MCP OpenCockpits | molettes et afficheurs (CRS, IAS/Mach, HDG, ALT, V/S), poussoirs et voyants des modes, F/D, A/T ARM, barre DISENGAGE |
| `cdu.yaml` | CDU OpenCockpits | touches, voyant EXEC et écran du CDU du commandant (`sim/FMS/…`) |
| `radio.yaml` | radio OpenCockpits Airbus | COM1, COM2, NAV1, NAV2 : fréquences active et en attente, bagues, transfert |
| `transpondeur.yaml` | EFDE IO32 | code et mode du transpondeur |
| `sim.yaml` | — | liaison X-Plane |

## MCP

- Les poussoirs envoient les commandes de l'avion (`laminar/B738/autopilot/*_press`), et les voyants suivent ses états (`*_status`).
- La fenêtre V/S reste éteinte tant que le mode V/S n'est pas engagé, comme sur l'avion (`blank_unless`).
- La bascule IAS / Mach (C/O) suit l'avion.
- À la connexion, la position des interrupteurs F/D et A/T ARM est envoyée à l'avion.

Les noms des commandes du 737 se trouvent dans son script `plugins/xlua/scripts/B738.glareshield/B738.glareshield.lua`.

## CDU

Le 737 de Laminar n'a ni MENU ni N1 LIMIT, mais DIR INTC et NAV RAD : sur le CDU OpenCockpits, MENU donne DIR INTC et N1 LIMIT donne NAV RAD. Seul le voyant EXEC existe dans cet avion. L'écran est lu dans les datarefs standard du FMS (16 lignes de 24 caractères, couleurs) et peut s'afficher sur l'[écran physique du CDU](../utilisation/cockpit.md#lecran-physique-du-cdu).

## Transpondeur

Quatre molettes codées en binaire sur 3 entrées chacune et un sélecteur OFF / STBY / ON, reliés au transpondeur standard d'X-Plane. Le code et le mode du matériel sont poussés vers l'avion à chaque changement et à la connexion.
