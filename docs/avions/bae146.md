# BAe 146 (Just Flight / Thranda)

```sh
bin/pepit-cockpit config/avions/bae146-jf
```

Le profil `config/avions/bae146-jf/` relie un cockpit équipé de cartes OpenCockpits et EFDE au **BAe 146 Professional** de Just Flight pour X-Plane 12 (code OACI B462 pour le -200). Les boutons propres à l'avion (Thranda) sont dans `fonctions.yaml`. Ils ont été relevés en lecture seule pendant qu'on cliquait dans le cockpit 3D, car les scripts de l'avion sont chiffrés.

| Fichier | Matériel | Ce qu'il relie |
|---|---|---|
| `mcp.yaml` | MCP OpenCockpits (737) | sélecteur de modes, AP, YD, consignes |
| `cdu.yaml` | CDU OpenCockpits | le CDU du copilote (UFMC de FJCC) |
| `transpondeur.yaml` | EFDE IO32 | code et mode du transpondeur |
| `jauges.yaml` | EFDE FDBUS | vitesse verticale (IVSI), angle des volets |
| `manettes.yaml` | Thrustmaster TCA Q-Eng 1&2 | 2 manettes → 4 moteurs |
| `carburant.yaml` | afficheur wifi (ESP8266) | quantités de carburant |
| `carte_vitesses.yaml` | écran à encre wifi (ESP32) | carte des vitesses selon la masse |
| `fonctions.yaml` | — | fonctions propres au 146 |
| `sim.yaml` | — | liaison X-Plane |

## Pilote automatique : le MCP 737 sur le 146

Le 146 n'a pas de MCP, mais un sélecteur de modes sur le glareshield et un boîtier AP / YD sur la console centrale arrière. Chaque bouton du MCP déclenche un mode, et sa LED suit le triangle du mode.

| MCP (737) | 146 | | MCP (737) | 146 |
|---|---|---|---|---|
| HDG SEL | HDG | | LVL CHG | IAS |
| VOR LOC | V/L | | SPEED | MACH |
| APP | GSL (plan ILS) | | N1 | TURB |
| ALT HLD | ALT | | CWS A | ALT ARM |
| V/S | VS | | CWS B | B LOC |
| LNAV | L NAV | | CMD A | AP (engage / désengage) |
| VNAV | V NAV | | CMD B | YD (amortisseurs de lacet) |

- La **barre DISENGAGE** baissée déconnecte le PA, comme le bouton de la poignée.
- Les **molettes** HDG, CRS1, CRS2 et ALT agissent sur les consignes standard. CRS2 écrit la course NAV2 côté commandant, la seule que lit la fenêtre COURSE de droite du 146.
- Les fenêtres **IAS et V/S** restent éteintes : le 146 n'a pas de consigne de vitesse ni de vitesse verticale, il tient la valeur du moment où le mode s'engage.
- Les **interrupteurs F/D** commandent les FD BARS (haut = ON).

Conditions pour engager le PA : AVIONICS MASTER A et B, A/P MSTR et YAW DAMP MSTR 1 et 2 sur ON au plafonnier. D'après le manuel, **V NAV n'existe pas** sur cet avion et il n'y a **pas d'automanette** : la poussée se règle toujours à la main.

## CDU

Le FMC du 146 est l'**UFMC** de FJCC, et non le FMS standard d'X-Plane. Il publie l'écran du **CDU du copilote** : le profil relie donc le CDU physique au CDU droit de l'avion (touches `sim/FMS2/…`, que l'UFMC intercepte, et voyant EXEC du copilote). L'écran est lu par l'API web d'X-Plane et décodé selon le format de l'UFMC : 14 lignes de 25 colonnes, petits caractères, cases de saisie.

## Jauges

- **Vitesse verticale** : `sim/cockpit2/gauges/indicators/vvi_fpm_pilot`, sur l'IVSI (module X27).
- **Volets** : le braquage réel (`flap1_deg[0]`), sur l'indicateur analogique. Un levier de volets matériel qui tombe un peu à côté du cran donne par exemple 23,7° au lieu de 24 : c'est la vraie valeur d'X-Plane.

## Manettes des gaz

Le TQ Thrustmaster à deux manettes pilote les **manettes de l'avion** (`thranda/cockpit/Throttle[0-3]`) : la gauche pour les moteurs 1 et 2, la droite pour les moteurs 3 et 4.

- Le 146 n'a **pas d'inverseur**. Le cran de reverse du TQ sert de ralenti, et la zone derrière lui donne **OFF** (carburant coupé, −0,1).
- Pour démarrer un moteur, on ramène la manette de OFF au cran : l'injection se fait.

!!! warning "À faire dans X-Plane"
    Désaffectez les deux axes du TQ (Réglages → Joystick → « None »), sinon X-Plane et Pepit écrivent tous deux la poussée.

## Carburant

L'afficheur wifi reçoit les trois réservoirs en kg : 201 aile gauche (réservoir n° 0), 202 aile droite (n° 1), 203 central (n° 2). Il calcule lui-même le total.

## Carte des vitesses

L'écran à encre affiche la carte des vitesses de la masse immédiatement supérieure à celle de l'avion : VR et V2 au décollage (volets 18°, 24°, 30°), VFTO, VER, et les VREF (33° et 24° à l'atterrissage normal, 30°, 18° et 0° en anormal). Le livret saisi est celui du **146-300** (« Non-Limiting Speed charts », 27 000 à 46 000 kg).

!!! note "-200 ou -300"
    La carte du 146-200 dans X-Plane donne des vitesses légèrement différentes (à 38 000 kg : VR 125 au lieu de 128, VREF 33° 120 au lieu de 119). Pour un autre livret, remplacez les pages dans `carte_vitesses.yaml` : l'écran n'a pas à être reprogrammé.

## Limites connues

- Les FD BARS commandées depuis le MCP retombent parfois.
- Le bouton AP s'engage au sol : au sol, le PA braque le manche.
